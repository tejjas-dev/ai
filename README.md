# AI Practicals

**Author:** Tejas Chavan

This repository contains 8 AI practical implementations based on accompanying practical course material. Each practical demonstrates a fundamental AI concept or algorithm implemented in Python using only standard library dependencies.

## Practical Index

| # | Practical | Topic | Path |
|---|-----------|-------|------|
| 01 | Vacuum Cleaner Agent | Simple reflex agent in a 2-room environment | `Practical-01-Vacuum-Cleaner-Agent/` |
| 02 | BFS Grid Pathfinding | Breadth-first search on a 5×5 grid with obstacles | `Practical-02-BFS-Grid-Pathfinding/` |
| 03 | 8-Puzzle A* Search | A* algorithm with misplaced-tile heuristic for 8-puzzle | `Practical-03-8-Puzzle-AStar/` |
| 04 | Tower of Hanoi BFS | BFS solution for Tower of Hanoi puzzle | `Practical-04-Tower-of-Hanoi-BFS/` |
| 05 | 8-Puzzle BFS | Breadth-first search for 8-puzzle (optimal for small depths) | `Practical-05-8-Puzzle-BFS/` |
| 06 | 8-Queens Backtracking | Classic N-Queens solved via recursive backtracking | `Practical-06-8-Queens/` |
| 07 | Rule-Based AI Chatbot | Regex-based pattern-matching conversational agent | `Practical-07-AI-Chatbot/` |
| 08 | Tic-Tac-Toe Minimax AI | Minimax algorithm with depth penalty for perfect play | `Practical-08-Tic-Tac-Toe-Minimax/` |

## Requirements

- Python 3.8+ (tested on 3.13)
- No external dependencies — pure standard library

## Run Instructions

```bash
# Navigate to any practical directory and run:
python3 main.py
```

Interactive practicals (03, 04, 05, 07, 08) will prompt for input. Use the sample inputs documented in each practical's README to reproduce the provided output screenshots.
